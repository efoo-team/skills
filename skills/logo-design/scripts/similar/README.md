# 類似検索（シンボルマークの形の照合）

案のシンボルマークが、公開されているアイコン集（ブランドのロゴと UI のアイコン）に形で似ていないかを確かめるスクリプトである。案の SVG を渡すと、比較対象の 6 つのアイコン集（アイコン集のアイコン計 24,399 件）から形の近いアイコンを得点の順に出し、案ごとの PNG と JSON、全案をまとめた PNG を書く。アイコン集のアイコンのうち、案に近いものを「類似アイコン」と呼ぶ。利用者が用意した SVG のディレクトリを `--extra-set` で追加のアイコン集として比較対象に足せる。

アイコン集とは、`--sets` の id で区別する比較の単位であり、npm パッケージ 4 つを 6 つに分けたものである（「比較対象のアイコン集」の表）。

比べるのは形だけである。色、文字としての読み方、意味は見ない。得点は目安であり、最後は PNG を目で見て判断する。

## 限界

- 照合の相手は、上の公開されているアイコン集（アイコン集のアイコン約 24,000 件）だけである。世の中のロゴ全体との照合ではない。
- 画像検索と、商標の図形検索はできない。既存のロゴや登録商標との類似の最終確認は、人間が行う。このスクリプトで「似たものが無かった」ことは、「似たものが世の中に無い」ことを意味しない。
- 形だけを比べる。意味は見ないため、同じ意味でも形が違えば得点は離れる。
- 線で描いたアイコン集のアイコンと、塗りの案のシンボルマークも、輪郭の法線の角度で比べられるが、線の太さが大きく違うと得点が下がる。
- ロゴタイプだけのロゴと書体は、比較対象に入っていない。`--extra-set` で、そのロゴの SVG を追加のアイコン集として足せば比べられる。
- 64×64 の解像度で比べるため、16 px 未満では判別できなくなる細部は見ない。

## 準備

`scripts/setup.sh`（このディレクトリの 1 つ上）を 1 回実行する。`$LOGO_DESIGN_HOME/similar/` に、`package.json` と `package-lock.json` をコピーして `npm ci` を行い、依存を入れる。`LOGO_DESIGN_HOME` の既定は `~/.cache/logo-design` である。依存が無いまま実行すると、`scripts/setup.sh を先に実行してください` を含むエラーで止まる。

必要なのは Node 22 以上だけである。外部コマンド（ImageMagick、rsvg-convert など）は使わない。

アイコン集ごとのマスクのキャッシュは `$LOGO_DESIGN_HOME/similar/cache/` に置く。初回の実行で、キャッシュが無いアイコン集のキャッシュを自動で作る（6 つのアイコン集の全部を作るため、初回だけ時間がかかる）。作り方やパッケージの版が変わったアイコン集も、実行時に自動で作り直す。作り直したいときは `cache/` を消す。

| 置き場所（`$LOGO_DESIGN_HOME/similar/` の下） | 内容 | 大きさ（目安） |
| --- | --- | --- |
| `node_modules/` | 依存（sharp、@xmldom/xmldom、アイコン集 4 パッケージ） | 約 250 MB |
| `cache/` | 6 つのアイコン集のマスク（`<id>.masks.bin`）と名前の一覧（`<id>.json`）。`--extra-set` のキャッシュ（`extra-*`）もここに置く | 約 13 MB |

## 使い方

```sh
node scripts/similar/similar.mjs <案.svg | 案のディレクトリ ...> --out <dir> [--top 15] [--rot] [--extra-set <dir>]
```

| option | 内容 |
| --- | --- |
| `--out <dir>` | 出力先。必須。無ければ作る |
| `--top <n>` | 案ごとに載せる上位の件数。既定 15 |
| `--rot` | 案を 90°・180°・270° 回した状態と、左右反転した状態（orientation）も試す。アイコン集のアイコンごとに、最も得点の高い案の回転・反転を選ぶ |
| `--sets <id,...\|none>` | 比べる組み込みのアイコン集。既定は 6 つすべて（id は「比較対象のアイコン集」の表）。`none` は組み込みを使わない（`--extra-set` だけと比べる） |
| `--extra-set <dir>` | 比較対象に足す追加のアイコン集。`<dir>` 直下の `.svg` をすべて使う。繰り返し指定できる |
| `--whole` | `#symbol` と `#background` を見ず、SVG 全体を形として使う |
| `--sigma <px>` | ぼかしの σ。既定 2 |
| `--weight <0-1>` | シルエットの重み。既定 0.1 |

標準出力には、案ごとの上位 10 件（順位、得点、IoU、`アイコン集の id/アイコン集のアイコンの名前`、`--rot` で案を回転・反転したときはその orientation）を書く。進捗は標準エラー出力に書く。2 回目以降の実行は、キャッシュを使うため初回より短い。

動作の確認は `node scripts/similar/selftest.mjs` で行う。一時ファイルは `/tmp` の下に作り、終了時に消す。確かめる内容は次の 5 点である。

- アイコン集のアイコン（simple-icons と lucide から 1 件ずつ）を案にすると、自分自身が得点 1.000・IoU 1.00 で 1 位になる
- 架空の非対称なシンボルマークを `--extra-set` の追加のアイコン集に置き、それを 90° 回した SVG と左右反転した SVG を `--rot` で渡すと、回転・反転する前のシンボルマークが 1 位になり、案の回転・反転（orientation）が元に戻る値（`rot270`・`mirror`）になる
- `<ID>.icon.svg` を置いた案のディレクトリを渡せる（アイコン背景の `#background` を除き、`#symbol` だけを比較に使う図形にする）
- 追加のアイコン集のキャッシュが再利用され、SVG を足すと作り直される
- 存在しない案は、メッセージを出して終了コード 1 で止まる

## 案の SVG

案は、SVG のファイル（複数可）か、案のディレクトリで渡す。ディレクトリを渡すと、直下の `<ID>.icon.svg` を名前順にすべて使う（案の ID `<ID>` と同じ）。

比較に使う図形は、次のように切り出す。`#symbol` と `#background` は任意の入力仕様で、無くても動く。

| `mode`（JSON の項目） | 条件 | 比較に使う図形 |
| --- | --- | --- |
| `symbol` | `#symbol`（`<g id="symbol">` など）がある | `#symbol` だけ。`#background`（アイコン背景の `<rect id="background">`）と、`#symbol` の外の描画要素は除く |
| `no-symbol` | `#symbol` が無く、`#background` がある | `#background` を除いた残り |
| `whole` | どちらも無い（simple-icons のような単色の SVG）、または `--whole` | SVG 全体 |

比較に使う図形は、描画した結果の不透明度（alpha）で切り出す。シンボルマークの色が白でも黒でも変わらない。画像全体を覆う不透明な背景が描かれている SVG は、背景と違う画素を比較に使う図形とし、その旨を JSON の `notes` に書く。`viewBox` か `width` と `height` が無い SVG、XML として読めない SVG は、原因を示して止まる。

## `--extra-set`（追加のアイコン集）

`--extra-set <dir>` は、`<dir>` 直下の拡張子 `.svg` のファイルを、組み込みの 6 つのアイコン集に足す追加のアイコン集にする。

`--extra-set` には、案が似てはいけない他社のロゴ（同じ領域の競合サービスのロゴなど）の SVG を置く。

- 結果の `set`（アイコン集の id）は `extra:<ディレクトリ名>`、`name` はファイル名から `.svg` を除いたものになる。ディレクトリ名が重なるときは `-2` を付ける
- 比較に使う図形は案と同じ規則で切り出す（`#symbol` があればそれだけ。画像全体を覆う背景は除く）。アプリアイコンのような背景付きの画像でも、シンボルマークの形で比べられる
- マスクは `cache/extra-<名前>-<パスのハッシュ>.*` に置く。キャッシュの鍵は、ファイル名・サイズ・更新時刻の一覧のハッシュである。SVG を足す・直すと、次の実行で作り直す。SVG を置いたディレクトリが無くなったキャッシュは、次の実行で消す
- 競合ロゴなどの画像の取り扱い（比較にだけ使い、成果物や公開物に含めない）は、実行者が守る。このスクリプトはディレクトリの中身を、キャッシュのマスク（64×64 の 2 値）以外には複製しない

## 出力

`--out` の下に次を書く。`<案のファイル名>` は、案の SVG のファイル名から `.icon.svg` か `.svg` を除いたものである（重なるときは `-2` を付ける）。案のディレクトリを渡したときは、案の ID（`<ID>`）と同じになる。`designs.json` の `name`（案の名前）とは別である。

| ファイル | 内容 |
| --- | --- |
| `<案のファイル名>.png` | 左に案、右に上位の類似アイコン。各類似アイコンに、順位、得点、輪郭（edge）・シルエット（sil）・IoU、アイコン集の id、類似アイコンの名前を付ける |
| `<案のファイル名>.json` | 項目は `design`（案のファイル名）、`file`、`mode`、`orientations`（試した案の回転・反転）、`notes`（注意）、`params`（比べ方の設定、各パッケージの版、`extraSets`）、`results[]`。`results[]` の各要素は、順位、`set`、`name`、`title`（simple-icons のみ）、`aliases`、`score`、`edge`、`silhouette`、`iou`、`orientation`（最も得点が高かった案の回転・反転）を持つ |
| `summary.png` | 全案を 1 枚に並べたもの。案ごとに左に案、右に上位の類似アイコン |

PNG の読み方。

- 各図形は比較と同じ規則で置く。外接矩形で切り出し、縦横比を保ち、48 px の枠の 56/64（42 px）に収めて中央に置く。アイコン集のアイコンの画像そのもの（余白を含む）を見せる図ではない
- 得点は、0.75 以上を橙、0.85 以上を赤で示す
- 類似アイコンの名前の後ろの `+N` は、同じ形のアイコン集のアイコンが N 件あり、1 件にまとめて載せたことを示す（Material Symbols の `NAME` と `NAME-fill`、lucide の改名前の名前など）。名前は `aliases` に残る
- `--rot` で回転・反転した案が最も近かったとき、類似アイコンの右に橙の破線の枠で、その回転・反転をした案を小さく置き、orientation の名前（例: `rot90`）を添える。orientation の名前は、左右反転（`mirror`）を先に、次に時計回りの回転を適用する順である（`mirror+rot90` は、反転して 90° 回した案）
- 文字は OS の書体で描く（Helvetica Neue、Helvetica、Arial の順）。これらが無い環境では、別の書体で描かれる

## 比べ方

1. **比較に使う図形の切り出し**: 案は上の表の `mode` で図形を切り出し、組み込みのアイコン集のアイコンは SVG 全体を、色を黒にして長辺 512 px で描画する。不透明度が 128 以上の画素の外接矩形で切り出す
2. **マスク**: 切り出した形を、縦横比を保って 56×56 に収め、64×64 の中央に置いて 2 値化する（縮小は面積平均。細い形が消えないよう、閾値は 0.5 と最大の被覆率の半分の小さい方）。アイコン集のアイコンも同じ処理を通し、`cache/` に 64×64 のビット列として持つ
3. **特徴**（`lib/features.mjs`）: マスクから 2 つの特徴を作る。edge は、軽くぼかした（σ 1.5）マスクの勾配から、輪郭の法線の角度（0°・45°・90°・135° の 4 つ。正負は区別しない）ごとの強さのマップを作り、σ（既定 2 px）でぼかして 32×32 に縮めた 4 枚を連結した単位ベクトルである。線で描いたアイコン集のアイコンと、塗りの案のシンボルマークでも、輪郭の配置が近ければ近くなる。sil は、マスクを σ でぼかして 32×32 に縮め、平均を引いた単位ベクトルである。塗りの量と配置を捉える
4. **得点**: `score = (1 − weight) × cos(edge) + weight × Pearson(sil)`。`weight` の既定は 0.1（輪郭の法線の角度のマップ 0.9、シルエット 0.1）。同じ形は 1.000 になる
5. **IoU**: 64×64 の 2 値のマスクの IoU（共通部分 ÷ 和集合）。順位には使わず、併記する。`--rot` のときは、最も得点の高い回転・反転をした案で測る
6. **`--rot`**: 案の回転・反転 8 通り（orientation。`none`、`rot90`、`rot180`、`rot270`、`mirror`、`mirror+rot90`、`mirror+rot180`、`mirror+rot270`）を試し、アイコン集のアイコンごとに最も高い得点とその orientation を選ぶ。対称な形で同じマスクになる回転・反転は 1 つにまとめる（先のものを残す）。同点は `none` を残す

`weight` は、得点に混ぜるシルエット（sil）の割合である。0 にすると、輪郭の法線の角度のマップ（edge）だけで比べる。大きくするほど、塗りの量と配置が近いアイコンが上位に出る。線で描くアイコン集（tabler-outline・lucide）のアイコンは塗りの量が少ないため、weight を上げるほど、線のアイコンを見つけにくくなる。塗りのアイコン集（Material Symbols の `-fill` など）のアイコンは、weight を上げると見つけやすくなる。比較対象に線のアイコン集と塗りのアイコン集が混ざるため、シルエットを少し混ぜる 0.1 を既定にしている。IoU は輪郭の配置を見ず、線で描いたアイコンと塗りのシンボルマークの対応を捉えにくいため、順位には使わず併記にとどめる。

## 得点の読み方

得点は 0〜1 で、同じ形は 1.000 になる。0.8 前後は、多くの案で、アイコン集の中にそれなりに近いアイコンがある水準である。最上位の得点は、次の表で読む。


| 最上位の得点 | 読み方 |
| --- | --- |
| 0.90 以上 | ほぼ同じ形 |
| 0.85〜0.90（赤） | かなり似ている。目で確かめる |
| 0.75〜0.85（橙） | 0.8 前後は多くの案で出る。目で確かめるが、似ているとは限らない |
| 0.65〜0.75 | 似ていない。確認は要らない |
| 0.65 未満 | アイコン集のどのアイコンにも似ていない形 |

| id | パッケージ | 版 | 件数 | 内容 | license |
| --- | --- | --- | --- | --- | --- |
| `simple-icons` | `simple-icons` | 16.33.0 | 3,462 | ブランドのロゴ（塗り） | CC0-1.0（ただし、ロゴ自体は各社の商標。パッケージの `DISCLAIMER.md`） |
| `lucide` | `lucide-static` | 1.51.0 | 1,865 | 線の UI アイコン | ISC |
| `tabler-outline` | `@tabler/icons` | 3.48.0 | 5,132 | 線の UI アイコン | MIT |
| `tabler-filled` | `@tabler/icons` | 3.48.0 | 1,046 | 塗り（filled）の UI アイコン | MIT |
| `material-outlined` | `@material-symbols/svg-400` | 0.47.6 | 6,438 | Material Symbols の outlined（`NAME-fill` は塗りの版） | Apache-2.0 |
| `material-rounded` | `@material-symbols/svg-400` | 0.47.6 | 6,456 | Material Symbols の rounded（`NAME-fill` は塗りの版） | Apache-2.0 |

件数は、同じ形のアイコン集のアイコンを 1 件にまとめた後の数である。

アイコン集は `$LOGO_DESIGN_HOME/similar/node_modules` に入り、skill には同梱しない。simple-icons の SVG は、著作権の観点では CC0 だが、描かれているロゴは各社の商標である。このスクリプトは照合のための読み取りにしか使わない。結果の PNG に載るロゴを、利用者の成果物に使ってはならない。

依存するそのほかのパッケージ: `sharp` 0.35.5（Apache-2.0。同梱のネイティブの libvips は LGPL-3.0-or-later）、`@xmldom/xmldom` 0.9.12（MIT）。

## 構成

| パス | 内容 |
| --- | --- |
| `similar.mjs` | 本体のコマンド |
| `selftest.mjs` | 動作の確認 |
| `package.json`・`package-lock.json` | 依存の宣言。`scripts/setup.sh` が `$LOGO_DESIGN_HOME/similar/` へコピーして `npm ci` する |
| `lib/preflight.mjs` | 依存の有無を、本体を読む前に確かめる（無ければ `scripts/setup.sh` を促して止める） |
| `lib/sets.mjs` | アイコン集の定義（組み込みの 6 つと `--extra-set`）と、アイコン集のアイコンの一覧 |
| `lib/cache.mjs`・`lib/build-worker.mjs` | アイコン集のアイコンを描画して `cache/` を作り、読む |
| `lib/design.mjs` | 案の SVG から比較に使う図形を切り出す |
| `lib/raster.mjs` | 描画、外接矩形、64×64 のマスク、回転・反転、ぼかし |
| `lib/features.mjs` | edge と sil の特徴 |
| `lib/search.mjs`・`lib/score-worker.mjs` | アイコン集のアイコンの特徴を worker で作り、案との得点を求める |
| `lib/report.mjs` | PNG の描画 |

依存の解決は、1 つ上の `scripts/lib/deps.mjs`（`LOGO_DESIGN_HOME` から解決する）を通す。
